# Slides

Slides of the seminar talk „Shapley-Analyse eines MLP“ (German, 30 minutes, 1 December 2026).

| File | Content |
|---|---|
| `Shapley_MLP_Vortrag.pptx` | final deck with speaker notes: slides 1–32 for the talk, a prepared audience question with its answer (33–34), sources (35–37) and reserve slides for questions (38–43) |
| `Shapley_MLP_Vortrag.pdf` | PDF export of the deck |

All result figures in the deck come from
[heatrisk-shap-analysis](https://github.com/amk0098/heatrisk-shap-analysis) (`outputs/figures/slides/`; `scripts/slide_figures.py` and
`scripts/mlp_figures.py`). The [paper](../paper/) explains every slide in more depth; Appendix B.5 maps slides to sections.
